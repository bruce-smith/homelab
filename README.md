# Homelab — NixOS Flake

Declarative config for the 3-node homelab cluster (k3s + NixOS).

|---|---|---|---|---|
| node0 | HP Pavilion dv6 | node0 | 192.168.3.126 | control plane |

## Layout

```
flake.nix                      # flake entry: builds node0/node1/node2
hosts/
  <node>/
    configuration.nix          # hand-tuned system config (SSH, sudo, kernel, user)
    hardware-configuration.nix # generated by nixos-generate-config (per machine)
```

## Deploy (nodes already have NixOS installed — no nixos-anywhere needed)

From a machine with Nix + this repo (the nodes themselves qualify):

```bash
# apply config for one node, built locally on that node
nixos-rebuild switch --flake .#node0

# apply remotely from your main PC (SSH as the node user, passwordless sudo is set up)
nixos-rebuild switch --flake .#node0 --target-host node0@node0
nixos-rebuild switch --flake .#node1 --target-host node1@node1
nixos-rebuild switch --flake .#node2 --target-host node2@node2
```

Requires the nodes' SSH aliases in `~/.ssh/config` (see Obsidian: Home Lab - Laptop Cluster Plan → SSH & Network Setup).
